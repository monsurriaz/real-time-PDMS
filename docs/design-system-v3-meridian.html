01 — Foundations

Colour

Cool graphite chrome, a true-white workspace on a cool grey page, one ultramarine accent. The warm beige is gone — it was what made the old build read as a template. Dark chrome is the navigation frame only; the workspace is never dark.

Redirects. Signing in lands on your role's default. Hitting another role's URL redirects to your own default — never a 403 screen, never a flash of denied content. Old paths (/book, /agent, /admin) redirect to their new homes so nothing 404s. An unapproved rider is redirected to /agent/pending from every other agent route. Visiting / while signed in shows the landing page with a link to your dashboard rather than auto-redirecting — a signed-in user is still allowed to read the public page.

Buttons

Disabled state

Neutral, never a washed-out accent. A tinted disabled button reads as broken rather than unavailable.
